# The Unusual Foods Around us
This project is a intercative web application showing the unusual foods found in South Africa and neigbouring countries.
It was built using HTML,CSS and Javascript
#Theme
Unusual foods, exploring unique and traditional foods eaten accross South Africa and neigbouring countries.

# Features
search - search for foods and see the results displayed dynamically.
details - click a result to view the full description in the details section.
favourites - save foods that catch your eye to a unique list of your creation.
compare - compare foods to get a simpler view of what to choose.
print - print the currently displayed food items.
